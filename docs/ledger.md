Archive index, trash, order (owner, 2026-10-30; 1.0.0025): an index file with one file per flow, kept below 3 MB, and a delete button on each flow behind a confirmation, then (same change) a Trash tab with Restore, the fold chevron before the name everywhere, and completion times on every finished row with every list ordered by them.
