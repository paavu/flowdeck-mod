# Security

flowdeck is a Claude mod: it runs inside Claude Code with the user's permissions. [README.md](README.md#privacy-what-it-reads-writes-and-runs) lists every file path it writes, the one process it can start (`Empty Trash`) and its one model request (Keep warm).

## Supported version

The latest release.

## Reporting a vulnerability

Report security problems privately through the repository's Security tab: https://github.com/paavu/flowdeck-mod/security, then "Report a vulnerability". Do not open a public issue for a vulnerability.

Include the version (`v…` in the panel's top row), what happened and how to reproduce it. Leave out tokens, transcripts and other private data.

Replies are best effort.
